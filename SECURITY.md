# Security policy

Report a vulnerability with the private security-advisory form in the LightPHI
GitHub repository. Do not open a public issue for an undisclosed vulnerability.

Include the affected revision, a minimal reproducer, expected impact, and any
known workaround. The maintainer will acknowledge the report, assess affected
versions, and coordinate a fix and disclosure. Only the latest released major
version receives security fixes while the project is pre-production.
